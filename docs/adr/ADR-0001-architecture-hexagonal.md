# ADR 0001 — Adopt Hexagonal Architecture with Vertical Slice Presentation Layer

## Status

Accepted

## Context
The project is expected to evolve while maintaining low coupling and clear separation of responsibilities.

## Decision

Use Hexagonal Architecture for the application layers and Vertical Slice organization for the presentation layer.

## Consequences

+ Better scalability
+ Better modularity
+ Easier onboarding
+ Clear feature boundaries
